# Nimba PTY LTD Website

A professional website for Nimba PTY LTD, showcasing smart water metering solutions for South Africa. Built with modern web development practices, accessibility in mind, and responsive design.

## 🚀 Features

- **Responsive Design**: Mobile-first approach with seamless experience across all devices
- **Accessibility**: WCAG compliant with proper ARIA labels, keyboard navigation, and screen reader support
- **SEO Optimized**: Semantic HTML, meta tags, and structured data for better search engine visibility
- **Performance**: Optimized CSS, JavaScript, and images for fast loading times
- **Modern UI/UX**: Clean, professional design with consistent branding
- **Cross-browser Compatible**: Works on all modern browsers

## 📝 Customization

### Updating Content
- Edit HTML files to change text content
- Replace placeholder images in the `assets/` folder
- Update contact information throughout the site

### Styling Changes
- Modify CSS variables in `styles/main.css` for color changes
- Adjust spacing, fonts, and layout as needed
- Update brand colors in the `:root` selector

### Adding New Pages
1. Create new HTML file following existing structure
2. Update navigation menu in all pages
3. Add page-specific styles to `main.css`
4. Test responsiveness and accessibility
